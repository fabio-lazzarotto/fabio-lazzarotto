## Featured project

### CRM Suprimentos
Full stack web system that manages the purchase requisition pipeline of a procurement team, from ERP approval to the purchase order. It replaced a set of macro-driven spreadsheets and became the daily tool of the buyers.

- Imports the Oracle ERP report, applies the business rules and keeps the full history
- Schedule per stage, SLA in business days (with holidays), traffic-light status and deadline renegotiation workflow
- Interactive dashboard with backlog, lead time, SLA adherence and buyer ranking, charts built in pure SVG
- Role-based access (admin, manager, buyer), bcrypt passwords, session control, audit trail and automatic backups
- AI assistant powered by the Claude API with tool use, answering questions about the pipeline within each user's permissions
- About 23k lines of code, 77 routes and 353 automated tests

`Python` `Flask` `SQLite` `pandas` `JavaScript` `HTML/CSS` `Jinja` `Claude API` `unittest`
